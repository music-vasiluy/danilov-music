# Сайт песен Данилы Васильева

Статический сайт, который автоматически публикует песни из Telegram-канала
[@Danilov_Vasilii_music](https://t.me/Danilov_Vasilii_music).
Тёмное оформление, кнопки «Купить» ведут на почту и телефон.

## Как это работает

```
Telegram-канал  →  бот  →  проверка на вашем ПК (каждый день в 15:00)  →  сайт на GitHub Pages
```

1. Бот добавлен в канал **администратором** и видит каждый новый пост.
2. Каждый день в 15:00 скрипт на вашем компьютере забирает новые посты через
   Telegram Bot API, скачивает аудио и обложки, обновляет `data/songs.json`
   и отправляет изменения на GitHub.
3. GitHub Pages отдаёт сайт — посетители сразу видят новые песни.

## Первое включение (5–10 минут)

### 1. Создайте бота

1. Откройте в Telegram **@BotFather** → отправьте команду `/newbot`.
2. Имя — любое, например «Данила Васильев — сайт песен».
   Username — должен заканчиваться на `bot`, например `danila_vasilev_music_bot`.
3. BotFather пришлёт **токен** (вида `1234567890:AA…`) — сохраните его.

### 2. Добавьте бота в канал администратором

1. Откройте канал → **Управление** → **Администраторы** → **Добавить администратора**.
2. Введите username бота и сохраните. Особые права не нужны.

> ⚠️ Бот «видит» только посты, опубликованные **после** его добавления.
> Если песни уже выкладывались раньше — опубликуйте их, пожалуйста, заново
> (или перешлите в канал ещё раз).

### 3. Вставьте токен в файл `sync\.token`

Откройте папку `danilov-music\sync` → создайте там файл с именем `.token`
(Блокнот: «Файл → Сохранить как» → имя `.token`, тип «Все файлы») и вставьте
в него одной строкой токен из BotFather. Файл хранится только на компьютере
и в GitHub не отправляется.

*Запасной вариант (необязательно):* чтобы запускать проверку ещё и кнопкой
в GitHub — добавьте токен в секреты: Settings → Secrets and variables → Actions → `BOT_TOKEN`.

### 4. Проверка

Двойной клик по `sync\run-local.cmd` — в окошке появится результат, подробности
запишутся в `sync\local-sync.log`.

Дальше всё работает само: **каждый день в 15:00** Планировщик заданий Windows
(задание «DanilovMusicSync») проверяет канал. Если компьютер в 15:00 был выключен,
проверка произойдёт при следующем включении.

## Как публиковать песни

Опубликуйте пост в канале:

- **аудиофайл** (прикрепите именно «Аудио», не «Файл») с названием — станет песней на сайте;
- **подпись** к посту — слова или описание песни: кнопка «Текст» откроет их, первые 4 строки видны сразу, остальное — по кнопке «Показать полностью»;
- **фото** в посте станет обложкой.

Запись появится на сайте при ближайшей проверке (каждый день в 15:00).
Ускорить: двойной клик по `sync\run-local.cmd`.

Полезно знать:

- Файлы больше **20 МБ** Telegram не отдаёт ботам — такая песня появится на сайте
  без плеера (с пометкой о размере).
- Если компьютер несколько дней выключен, ничего страшного: при следующем включении
  проверка догонит пропущенное. Можно и вручную — двойной клик по `sync\run-local.cmd`.
- При желании бота можно сделать автором постов: он и так видит всё, что публикуется.

## Что легко поменять

| Что | Где |
|---|---|
| Почта и телефон | `assets/js/app.js` → объект `CONTACTS` в самом верху |
| Цитаты Данилы Васильева | `data/quotes.json` (блок «Слово автора» в разделе «О музыке») |
| Фотографии | `assets/img/photos/` — замените файлы на свои (имена те же) |
| Тексты на странице | `index.html` |
| Слова песни | подпись к посту в Telegram (на сайте — кнопка «Текст») |
| Оформление, цвета | `assets/css/style.css` (переменные в `:root`) |

## Локальный предпросмотр

```bash
python -m http.server 8000
```

- <http://localhost:8000> — как сайт выглядит сейчас;
- <http://localhost:8000/?preview=demo> — оформление с примерами песен.

Проверка новых песен прямо сейчас — двойной клик по `sync\run-local.cmd`
(подробности записываются в `sync\local-sync.log`).
Время ежедневного запуска можно поменять в Планировщике заданий (задание «DanilovMusicSync»).

## Структура

| Путь | Что это |
|---|---|
| `index.html` | Страница сайта |
| `assets/` | Стили, скрипты, шрифты, аватар, иконки |
| `data/songs.json` | Список песен (обновляется автоматически) |
| `data/songs.example.json` | Примеры для предпросмотра `?preview=demo` |
| `data/demo/` | Демо-мелодии для предпросмотра (в игре на сайте не участвуют) |
| `data/quotes.json` | Цитаты Данилы Васильева для раздела «О музыке» |
| `assets/img/photos/` | Фотографии (портрет и семейный альбом) |
| `audio/`, `covers/` | Скачанные из Telegram песни и обложки |
| `sync/sync.mjs` | Скрипт синхронизации с Telegram |
| `sync/run-local.ps1`, `sync/run-local.cmd` | Ежедневная проверка с ПК (в 15:00) |
| `sync/.token` | Токен бота (только на вашем ПК, в GitHub не отправляется) |
| `.github/workflows/sync.yml` | Запасной запуск синхронизации по кнопке |
